# altare-site

A simple landing page served from a free **Altare** Linux Sandbox
(`tsukuyomip-sandbox`, Ubuntu 24.04, Singapore).

## Rule

The sandbox is treated as **public and disposable**: anything placed on it
may be seen or lost. Only public-safe contents live here — no secrets,
no credentials, no personal data.

## Contents

- `index.html` — the landing page (single self-contained file, no external assets)

## Deployment

The sandbox pulls this repository and serves `index.html` as a static page.
